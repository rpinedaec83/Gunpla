# Patterns

This folder contains reusable baseline patterns for architecture and UX.

Subfolders:
- `stack-patterns/` -- architecture and platform baselines
- `ux-patterns/` -- layout and navigation baselines

Each pattern family supports:
- active baseline files used as current source of truth
- template catalogs used to select and adapt a baseline

Keep this folder generic and reusable. Do not store environment-specific credentials, tenant values, or tokens here.
